# 暂未开通服务地区

2026-10-06 用户确认：香港特别行政区、澳门特别行政区、台湾省、金门县及三沙南沙区暂不提供服务。金门县虽在现有地区目录中列为福建省／泉州市／金门县，也按本服务策略停用，不改变其目录身份。三沙南沙区限定为海南省／三沙市／南沙区 `460303`，兼容旧目录的 `460322`／南沙群岛；广州南沙区 `440115`、三沙西沙区及旧中沙条目没有被停用。

## 行为

- 地区选择保留地区名称，标注“暂未开通服务”；没有可选的服务端点，不用市级坐标替代区县坐标。
- 点击这些地区或定位结果落在未开通范围，弹窗提醒，不修改已有地区选择。
- 后端注册拒绝请求，返回 `422 region_service_unavailable`，不创建账号或登录凭据。
- 新寄信、寄送估算和迁入这些地区同样拦截。已有账号仍可登录、修改昵称并迁出；已有信件的读取、重试和运输事实不改写。
- 无新增服务范围之外的地址推断；保留简繁体和常见别名拦截，避免历史客户端绕过地区选择。
