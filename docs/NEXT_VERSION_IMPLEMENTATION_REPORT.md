# 下一版本实施报告

> 2026-10-03。状态：代码与自动化回归完成，云端新版后端已部署，Android APK 1.1.0 已构建；真机推送标识获取失败，功能与远程送达验收待办。不是 Final Gate PASS。

## 实现范围

### 图片与写信时间

- 单封最多 9 张、单张最大 10 MiB；支持相册和文件选择。iPhone HEIC / HEIF 先转 JPEG，再复查上传体积。保留现有非空文字要求，本次没有改为纯图片信件。
- 服务端实际解码校验 JPEG、PNG、WebP、GIF、AVIF，不接受 SVG 或伪造 / 截断内容；限制总解码像素 6400 万，降低压缩炸弹风险。多帧图片也计入总解码像素上限。
- 图片和头像 AES-256-GCM 加密落盘，复用现有正文加密密钥，文件名为随机 UUID；密文文件权限 `0600`。通过鉴权接口读取，不提供公共图片目录或免鉴权链接。
- 正文、图片与时间戳：寄件人沿用已有权限；收件人到 `DELIVERED` 后 API 才返回，手机界面继续保留原有拆阅 `OPENED` 门禁。第三人直连原图 / 缩略图也不能读取信件图片。
- 正文内的“写于”记录草稿首次输入文字 / 添加图片的时间；发送或网络重试不改变它。旧信无法追溯真实写信时间，迁移仅以原 `createdAt` 回填，此值是历史兼容近似。
- 发送超时后锁定同一请求内容、写信时间、图片 ID 和幂等键，防止修改草稿后重复寄出；明确未创建的业务拒绝允许修正后重新提交。
- 图片缩略图由鉴权接口返回，完整原图按需打开；切换账号后不得继续渲染旧账号已加载的图片。
- 已上传但未绑定的图片超过 24 小时不能再用于寄信；当前清理在该用户下一次上传时触发，且单用户未绑定图片最多 36 个。未实现全站定期磁盘巡检，需在上线维护中安排过期 / 孤儿文件清理和容量监控。

### 地区、资料与头像

- 注册使用省 / 市 / 区县联动选择，可搜索，切换上级后清空下级。
- 请求前台定位权限，反向地理编码后匹配下拉项；拒绝权限、定位异常或 15 秒超时均回到手动选择。不申请后台定位，也不因定位自动保存个人地区。
- 用户开始手选后，迟到的定位结果不得覆盖手选值；保存期间也不回填定位结果。
- 行政区数据离线固定为 `modood/Administrative-divisions-of-China` 的指定提交并保留 MIT 许可，原数据行政区截止 2023-06-30，并非 2026 年实时区划。当前仅覆盖现有路网支持的大陆 31 个省级地区；不伪造其他地区的驿站支持。
- “我的”新增个人资料编辑与头像选择入口。名字 / 地区可保存；头像可从相册 / 文件替换，旧头像不再可访问。既有信件身份快照不改写。

### 地区修改与运输

- 保存新地区后，已有寄给该用户的非终态信件记录新目标地区。
- 当前运输段保持原起终点、时长、已抽取结果和记录；抵达原定下一驿站后立即从该站按新地区重算剩余路线并继续出发。
- 已在末端派送时，从最后一个驿站立即重算；同站换区重新开始末端派送，不把新地址的派送时间回填到过去。
- 连续修改采用最后保存的目标，较早尚未应用的变更标记为被替代。创建新信、初始化路线、修改资料与 Worker 推进协调锁，避免丢失最新目标或改写当前段。
- 编辑前先按旧路线追平当前模拟时刻；若此时实际已送达，保留原目的地。已送达、永久丢失、销毁信件不改道。
- 保留已完成路段和旧末端派送事实，新增目的地版本区分多次派送。历史保留不依赖用户是否曾打开物流页面。未知站点等失败会回滚资料、运输追平和改道请求。
- 不修改随机源、已有异常恢复规则、正文可见性或收件人的事实权限。
