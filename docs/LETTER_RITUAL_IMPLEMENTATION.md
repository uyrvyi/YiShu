# 寄信与拆信仪式

## 实现范围

- 固定复古信封、应用邮票与封口、浅色信纸，无外观选择或新增设置。
- 确认发送立即收起键盘，900ms 折叠装信与原有请求并行；信件创建、路线建立及装信完成后，900ms 自动封口，保持封好的信封 1000ms 后进入详情。减少动态效果时仍保留这一秒停留。
- 沿用创建幂等键及路线失败的已保存编号；失败保留草稿，不重复创建。iOS 错误提示在发送弹层关闭后显示。
- 收件人仅在送达后可点击“拆开”。按用户最终确认，改为点击完整信封中央的骑缝章，不保留撕动手势或进度条。
- 拆阅成功后重新取信，确认已拆阅且正文可解密，测量信封位置与真实信纸高度后，用约 1400ms 的非线性时间线翻开信封、抽出并放大同一张正文信纸。纸张位于信封前后层之间，以裁切逐步露出正文，再连续移动到阅读浮层；不再用示意纸淡出、另一张阅读纸淡入。全程同一原生 Modal、同一纸张节点，不跳转独立页面；动画中禁止滚动。
- 详情页用统一浅色信纸展示已授权的正文、图片和写信时间；点击正文可再次展开，阅读浮层轻点正文或空白处后约 360ms 缩回详情内信纸。正文滑动不收起，图片点击继续进入图片预览。
- 信纸长度由内容自然撑开，阅读时滚动整张信纸，不在固定高度纸张内滚动正文；正文行距 32，配相同间距的浅色横线。已拆阅信再次进入详情不自动弹出，不显示额外阅读按钮。
- 阅读浮层默认在安全区内水平、垂直居中；内容高度超过可用空间时顶部对齐并整张滚动。上下空白均可轻点收起，展开与缩回的坐标包含居中偏移。
- 减少动态效果时使用短过渡；骑缝章具有无障碍按钮语义，默认无音效。发送和拆阅有单次请求保护，后台暂停动画，关闭或切换账号后不展示晚到内容。
- 兼容 Expo Go，无新增原生依赖，不改数据库、加密或运输规则。另按用户新增要求：搜索自己时弹窗且不确认收件人；后端发送接口同样拒绝自己的账号或 UID。

## 一次真机复验

1. 确认发送：键盘收起、装信、请求成功后封口、停留一秒、进入详情；连续点击不重复创建。
2. 已送达未拆阅信：先看不到正文、图片和写信时间；点击“拆开”后看到完整信封，点骑缝章后翻盖、弹出内容信纸，轻点缩回详情。
3. 再次进入已拆阅信：详情直接展示正文；没有额外阅读按钮或自动弹层。
4. 失败重试、减少动态效果和辅助功能已用状态测试覆盖；确认未送达仍不能拆阅，不将单元测试写成真机操作结果。
